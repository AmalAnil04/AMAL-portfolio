# Amal Anil · Portfolio

Personal portfolio website: B.Tech CSE student focused on data analytics, business analysis and UI/UX design.

## Live site
Hosted with GitHub Pages: https://AmalAnil04.github.io/AMAL-portfolio/

## Projects update automatically
The Projects section reads your public repositories from the GitHub API each time the page loads, so new commits and new repos appear without editing the site.

- Add the topic **featured** to a repository to show it (up to 6, newest first).
- With no `featured` repos, the 3 most recently updated non-fork repos are shown.
- Forks, archived repos and any repo with "portfolio" in its name are skipped.
- A repo's description, main language, topics and live-demo URL ("Website" field) become the card text, tags and links.
- If the GitHub API can't be reached, the page shows the built-in project cards.

## Files
- `index.html`: the whole site (HTML, CSS, JS)
- `Amal_Anil_Resume.docx`: file behind the Download resume button

## Deploy
1. Repo: https://github.com/AmalAnil04/AMAL-portfolio (public).
2. Push these files to the root of `main`.
3. Settings → Pages → Deploy from a branch → `main` / root.
